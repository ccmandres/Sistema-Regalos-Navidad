# Sistema Software Regalos de Navidad - Municipalidad de San Joaquín

Sistema digital de registro, validación y trazabilidad para la distribución de 13.500 juguetes navideños a beneficiarios de la comuna de San Joaquín.

## 🚀 Flujo de Trabajo Git
1. Toda nueva característica se trabaja en una rama derivada de `develop`: `feature/nombre-tarea`.
2. Para integrar cambios a `develop`, se debe abrir un **Pull Request (PR)** y solicitar revisión a un compañero.
3. La rama `main` se reservará únicamente para versiones estables listas para evaluación.
